Calibrate your strip

      

        1. Step through LEDs to find the first light and count. The test uses
        low brightness and pauses your current lighting.
      

      

        
        
      

      

        
      

      

        2. Set the route. In the edge test, red is left, green is top, blue is
        right and amber is bottom. Adjust offset and direction until they match.

Install update and restart?

      

        Your settings will be saved. Lighting continues during download, then
        stops while DynamicLight installs and restarts. Your existing startup
        and capture recovery settings still apply.
      

      

      

        
      

    
    
      

        
Studio editor

        
      

      

        Simulated preview. Hardware keeps its current scene until Apply. Global
        brightness and comfort limits still apply.
      

      
      
      

        

          
        

        

          Layers blend in order using opacity. Keyframe positions run from 0 to
          1000. Finite sequences hold their final frame. Up to four layers and
          sixteen stops per layer.
        

        

        
        

          Effect file
          
        

      

      

        

          
        

        

          LED numbers follow the calibrated route before physical
          reversal/offset. The ① marker shows the first hardware LED. Zones
          scale proportionally when LED count changes. Last overlapping zone
          wins. Unassigned LEDs retain the underlying scene.
        

        

          
        

        

        

        

          
        

        

      

      

        

          RGB temperature is an approximation. An RGB strip cannot guarantee a
          neutral white point or spectral accuracy. Calibrate with a meter;
          temperature alone is not a measured result. Applying bias lighting
          clears decorative zones.
        

        

          
        

        
      

      

        
        

          
        

      

      

      

        
      

    
    
      

        
Capture source

        
      

      
      

        The outline previews the sampled area; no screenshot is taken here.
        Selected edges map to the calibrated LED route. Changing source stops
        capture until you press Start / Retry.
      

      
      

        
      

      

        
      

      

        Window capture follows movement and resizing. Minimized, closed, or
        revoked sources stop or fall back to Music in Blend; Retry after
        restoring them. Select windows again after restarting DynamicLight.
        Protected video may be black. macOS requires screen-recording
        permission; Linux requires X11.
      

      

      
    
    
      

        
RGB sequences

        
      

      

        Record generated LED colors only, never screenshots or audio. Up to 60
        seconds / 1800 frames. Recording does not start lights or capture.
        Export to keep a file before replacing the current sequence.
      

      

        Record current lighting
        
        

          
        

        

      

      

        Offline playback
        

        
        

          
        

        
        

        
        

          Non-looping playback holds its final frame. Recorded intensity can be
          dimmed; global comfort limits still apply. Decorative zones are
          ignored during replay. Playback settings can be saved as a scene;
          another computer also needs the matching RGB file.

Install update and restart?

      

        Your settings will be saved. Lighting continues during download, then
        stops while DynamicLight installs and restarts. Your existing startup
        and capture recovery settings still apply.
      

      

      

        
      

    
    
      

        
Studio editor

        
      

      

        Simulated preview. Hardware keeps its current scene until Apply. Global
        brightness and comfort limits still apply.
      

      
      
      

        

          
        

        

          Layers blend in order using opacity. Keyframe positions run from 0 to
          1000. Finite sequences hold their final frame. Up to four layers and
          sixteen stops per layer.
        

        

        
        

          Effect file
          
        

      

      

        

          
        

        

          LED numbers follow the calibrated route before physical
          reversal/offset. The ① marker shows the first hardware LED. Zones
          scale proportionally when LED count changes. Last overlapping zone
          wins. Unassigned LEDs retain the underlying scene.
        

        

          
        

        

        

        

          
        

        

      

      

        

          RGB temperature is an approximation. An RGB strip cannot guarantee a
          neutral white point or spectral accuracy. Calibrate with a meter;
          temperature alone is not a measured result. Applying bias lighting
          clears decorative zones.
        

        

          
        

        
      

      

        
        

          
        

      

      

      

        
      

    
    
      

        
Capture source

        
      

      
      

        Lights follow the edges of the selected area. For a video inside a
        browser page, select just the video to exclude white margins and toolbars.
        Changing source stops capture until you press Start / Retry.
      

      

        
        
        
        

          Preview captures one image of this window, kept only while this dialog
          is open. Drag over the video in the preview, or enter percentages.
          The window follows its visible tab; switching tabs changes the content.
        

        
      

      
      

      

        
      

      

        Areas keep their relative position when the window resizes; reselect the
        video after changing the page layout. Fullscreen video can use the whole
        window. Minimized, closed, or
        revoked sources stop or fall back to Music in Blend; Retry after
        restoring them. Select windows again after restarting DynamicLight.
        Protected video may be black. macOS requires screen-recording
        permission; Linux requires X11.
      

      

      
    
    
      

        
RGB sequences

        
      

      

        Record generated LED colors only, never screenshots or audio. Up to 60
        seconds / 1800 frames. Recording does not start lights or capture.
        Export to keep a file before replacing the current sequence.
      

      

        Record current lighting
        
        

          
        

        

      

      

        Offline playback
        

        
        

          
        

        
        

        
        

          Non-looping playback holds its final frame. Recorded intensity can be
          dimmed; global comfort limits still apply. Decorative zones are
          ignored during replay. Playback settings can be saved as a scene;
          another computer also needs the matching RGB file.
        

        

          
        

      

      

    
    
      

        
Lighting routines

        
      

      

      

        Changes are drafts until Save. Routines run while DynamicLight is open.
        App rules and cues respect Stop. Scheduled actions may turn lights on at
        their chosen time; pause schedules to override them.
      

      

        Recurring schedules
        
        

        

          
        

        

          
        

        

          
        

        

          First matching row wins. Missed times, startup/current-minute edits
          and wake-up events are skipped. Clock changes follow the new local
          time; repeated hours run at most once per day, missing hours are
          skipped. Scenes are saved copies; re-add a schedule to use an updated
          profile. Capture scenes require manual Start.
        

      

      

        Application rules
        
        

        

          
        

        

          First matching row wins. The previous scene returns on focus loss or
          exit. Manual lighting changes override the rule until focus changes.
          Capture scenes restore stopped and need fresh Start. Application names
          stay on this computer. OS permissions may be needed on macOS; Wayland
          does not expose active applications.
        

        
      

      

        Focus and break timer
        

          
        

        
Timer stopped

        

          
        

        

          Timers pause after sleep or a long interruption and stop when the app
          exits. Save resets the timer. Each cycle includes a focus phase and a
          break; the focus cue also marks completion.
        

      

      

        Temporary cues
        

          Enable only the sources you want. Cues never turn stopped lights on,
          and the current scene continues underneath. One pending cue is kept;
          newer events replace it. No notification content is read.
        

        

          
        

        

          
        

        

          
        

        
        

          
        

        

          Equal start/end means quiet all day. Brightness and transition comfort
          limits apply to every cue.
        

      

      
      

    
    
      

        
Controllers & monitor layout

        
      

      

        Each strip has its own mode, calibration, display binding and routines.
        Main, Quick controls, tray and CLI commands control the selected strip.
        Up to eight controllers may run independently.
      

      

        
      

      

      

        USB bindings
        
        

          
        

        

          Bind the main strip before adding another. Only supported lighting
          interfaces are listed. Serial identities survive port changes when
          available; controllers without unique serials may need rebinding after
          a port or host change. Close other lighting apps before starting.
        

      

      

        Preview routing
        
        

          
        

        

          
        

        

          The larger dot marks the first physical LED. Dragging changes this
          diagram only. Mappings and route values remain drafts until Apply;
          closing discards them. The Studio editor offers individual LED/edge
          selection and zone previews for the selected strip.
        

        

          
        

      

      

        Group controls
        

          
        

        

          Group scaling preserves individual brightness values. Start all
          explicitly starts each configured mode, including screen/audio
          capture. One unavailable controller does not stop the others. Changes
          here are immediate.
        

      

      

        Windows / Mac / Linux USB handoff
        

          Physical USB switching or unplugging is required. DynamicLight does
          not transfer USB ownership over the network. Release stops this strip,
          closes its USB handle and pauses its automatic rules. Group Start
          skips released strips; explicit Start takes control again.
        

        
        
        

        
        

          Import retains this computer's USB/display bindings and comfort
          limits. Select a compatible USB interface, then Start when ready;
          reconnect recovery applies the profile when the strip appears. Capture
          needs fresh consent; Replay also needs its matching RGB sequence file.
        

      

      

        Ambient brightness for the controlled strip
        
        
        

        

          
        

        

          Manual brightness changes override the sensor until Resume sensor,
          Save sensor settings or an app restart. Group scaling and comfort
          limits still apply. Sensor changes never start lighting. macOS uses
          the external sensor input; supported Windows and Linux IIO sensors
          appear above.
        

        

          
        

        

        

          External sensor input
          

            A local sensor tool can atomically write a JSON object containing
            lux and a Unix timestamp in seconds, refreshed at least every 30
            seconds, to:
          

          

          {"lux":120,"timestamp":1792400000}
          

            Use the current timestamp. The file is limited to 1 KiB. No network
            connection or executable plugin is needed.
          

        

      

      

    
    
      

        
Games & plugins

        
      

      
      

        Start ordinary lighting first. Extensions never start a strip or grant
        capture permission. Stop, manual scene changes, calibration and
        suspension cancel active plugin effects.
      

      

        Counter-Strike 2 telemetry
        

          Opt-in Valve Game State Integration over loopback only. Choose events
          and zones along the calibrated LED route. No process injection. Cues
          respect quiet hours and comfort settings; the ordinary scene continues
          underneath.
        

        

        
        

        

          Copy the exported gamestate_integration_dynamiclight.cfg from
          Downloads into Counter-Strike Global Offensive/game/csgo/cfg, then
          restart the game. Each enable creates a new local endpoint and
          credential: export and replace the setup again. Telemetry is disabled
          on app restart. Remove the cfg to stop game posts. Ten seconds without
          valid telemetry, leaving the game, or disabling restores the ordinary
          scene. Spectated players are ignored.
        

      

      

        Declarative plugins · API v1
        

          Up to 16 local JSON plugins, 32 KiB each. Effects use bounded
          compositions; integrations receive only selected numeric game events.
          Plugins cannot execute code, read files, use the network or capture,
          or control USB directly. All plugins restart disabled.

Phone remote

        
      

      

        Use a phone on the same private network. Choose an interface and strip,
        then explicitly enable HTTPS access. The remote can change power,
        brightness, solid color and saved offline profiles. It cannot start
        capture or read captured frames/audio.
      

      
      
      

      

      
Verify this host

      

        This session uses a self-signed certificate. Your browser may show a
        certificate warning. Compare the SHA-256 fingerprint in its certificate
        details with the value below before pairing. Browser support varies; if
        it cannot verify or accept this certificate, use another browser. The
        app never installs a trusted certificate or changes firewall settings.
        Do not forward this port to the internet.
      

      

      
      

        Public certificate PEM
        

      

      
Pair a phone

      

        The code expires after two minutes or five attempts and can pair one
        phone. Up to eight phones per session. Give each phone a recognizable
        name.
      

      

      
      

      

        Restarting or disabling the remote revokes every phone and changes the
        HTTPS endpoint and certificate. Sleep or a network change may disconnect
        the phone; use Reconnect after waking. Enable again if this computer's
        address changes.
